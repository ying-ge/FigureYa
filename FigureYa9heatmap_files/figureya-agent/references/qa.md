# 图型特定验收

| 图型 | 数值检查 | 视觉检查 |
|---|---|---|
| 热图 | 方向、ID顺序、距离/聚类、scale、NA、注释对齐、双矩阵键一致 | 色标范围/中心、类别与连续色标区别、标签密度、树/分块真实对应 |
| 火山 | effect单位/方向、raw P/FDR、阈值边界、p=0/NA、高亮ID | 阈值线、被截点数、图例、标签重叠与越界 |
| 分布/配对 | 每组n、独立单位、配对完整性、检验/校正 | 原始点、连线配对、密度对小样本的误导、显著性括号裁切 |
| 相关/一致性 | 对齐、实际样本数、缺失处理、相关方法；一致性差值与均值及界限算法 | 轴单位、系数/区间/图例、等比例轴需求、离群点可见性 |
| PCA/UMAP/PCoA | 标准化、输入方向、解释方差、随机种子、距离定义 | 元数据颜色/形状一致、坐标轴正确标注、凸包/椭圆含义 |
| 生存 | time/event映射、删失、风险表时间点、组内事件数 | 删失标记、置信带、风险表对齐、随访不足的尾部展示 |
| ROC/校准/DCA | 阳性类、分数方向、验证集、概率范围、删失方案 | 轴与参考线、AUC/CI标签、有效阈值范围、多模型图例 |
| 森林 | CI包含点估计、比值>0、参考线0/1、模型和样本数 | 对数刻度是否正确、超界箭头、标签列与点对齐 |
| 组成 | 分母、闭合总和、聚合权重、missing/other定义 | y轴范围、类别颜色固定、小类别合并有据 |
| 桑基/网络/集合 | 权重守恒假设、重复边/成员、交集计数、节点ID | 宽度与权重、重叠、方向、排序、交集遗漏 |
| 单细胞/空间 | assay/layer、供体重复、注释、坐标/切片对齐 | 点大小与遮挡、空间纵横比例、表达零值和NA区分 |

最终预览必须来自最终脚本和真实绘图数据。任何代码改动后至少重跑受影响输出；不要把旧预览附在新脚本旁。没有实际执行时写not-run并列明可复现命令和阻塞项。
